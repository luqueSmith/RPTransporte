# APC Transporte Web v1.8

Actualización de interfaz para consulta más rápida del reporte de transporte.

## Novedades
- Filtro por fecha (Desde / Hasta).
- Períodos cerrados desplegables para reducir el desorden visual.
- Mayor separación y claridad entre períodos en móvil.
- Logo del navbar funciona como acceso para volver arriba.
- Favicon APC personalizado.

No requiere ejecutar SQL nuevo ni actualizar la APK.
